## Event Objectives

The event introduced current AWS AI trends, AI agents, open-source AI, and practical ways to turn AI capabilities into business value. It also provided an opportunity to connect with the AWS Vietnam community and learn from engineers working with cloud infrastructure and software development.

## Speakers and Topics

- **Henry Duc Bui:** Ship Fast with AI, Not by AI.
- **Nguyen Thu (Yuna):** From AI Trends to Business Value - Sales Track.
- **Nam La:** AI Trends Through the Lens of an Infrastructure Engineer.
- **Tuan Vu:** OpenClaw - The Rise and Practice of Open-Source AI Agents.

## Key Highlights

- Generative AI and coding assistants improve the inner development loop, but the outer loop still requires evaluation, testing, integration, and deployment.
- Repository documentation, lint rules, CI checks, and reusable skills help automate and standardize development workflows.
- Cloud infrastructure is moving from reactive operations toward proactive approaches using AIOps, FinOps, and proactive security.
- AI is becoming a practical support tool for software development, system operations, data analysis, and infrastructure optimization.

## Key Takeaways

- AI should support engineering judgment rather than replace it.
- Code review should focus on architecture, component interactions, state management, error handling, and security risks.
- Reusable documentation, lint rules, and automated tests improve development quality.
- Engineers should continue developing skills in cloud infrastructure, monitoring, security, cost optimization, and AI agents.
- Effective AI usage requires clear context, good prompts, guardrails, and human review.

## Application to My Learning

The event helped me connect AWS knowledge with practical topics such as inner and outer development loops, AIOps, FinOps, prompt engineering, context engineering, and guardrails. These ideas are useful for improving the reliability, security, and maintainability of cloud applications.
